# Qazi Urdu Poster Designer & Writer

Urdu poster / banner designer with full editing tools — desktop (tkinter) and
Android (Kivy) versions sharing the same rendering engine.

- **Android build** (APK via GitHub Actions): see [`android/`](android/) and
  `android/README.md` for features and build instructions.
- **Desktop app**: `qazi_poster_app.py` (Windows).

Highlights: Urdu text (Nastaleeq fonts + keypad), multiple text boxes with
arc/rotation/opacity/word-spacing, picture overlays with crop / background
eraser / adjuster, layer ordering, project save/open (`.qazip`), and PNG/JPG/PDF
export.
